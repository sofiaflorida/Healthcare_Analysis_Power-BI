# Healthcare Analytics Dashboard (Power BI)

This is my first Power BI project based on a healthcare dataset.

## Project Overview
An interactive dashboard analyzing:
- Patient demographics and diagnosis trends  
- Doctor performance and workload  
- Hospital billing and insurance provider analysis  
- Length of stay trends  
- Age, gender, and test result insights  

## Tools Used
- Power BI  
- DAX  
- Power Query  
- Data Modeling  
- Data Visualization
